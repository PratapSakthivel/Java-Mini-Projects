# 46 WaterBillCalculator

## Overview
`WaterBillCalculator` is a standalone Java application designed to demonstrate fundamental programming practices.
**Objective**: Calculates water bill.

## Compilation & Execution

```bash
javac WaterBillCalculator.java
```

Execute the compiled application:
