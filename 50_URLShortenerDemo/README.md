# 50 URLShortenerDemo

## Overview
`URLShortenerDemo` is a standalone Java application designed to demonstrate fundamental programming practices.
**Objective**: Creates deterministic short codes.

## Key Concepts Covered
- **Core Java Syntax**: Method declarations, standard library imports, and variable scopes.
- **Data Handling**: Efficient data manipulation and console stream management.
- **Best Practices**: Clean code structure, standard naming conventions, and idiomatic Java logic.

## Compilation & Execution

Compile the source file using the standard Java Development Kit (`javac`):
```bash
javac URLShortenerDemo.java
```

Execute the compiled application:
```bash
java URLShortenerDemo
```
